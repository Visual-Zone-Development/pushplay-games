# Researching inspiration

Before designing, look at 2–3 games that already nail the feel you're after. The goal is to learn **why** they're fun, then borrow mechanics and feel, not content.

## Method

1. **Pick references.**
   - Any game the player named comes first.
   - Otherwise choose well-loved games in the chosen genre that hit the same fun targets (see [framework.md](framework.md)). The offline canon below is a good start.
   - One reference can come from outside the genre, for the twist.
2. **Research quickly.** If web search is available, a few searches are enough, e.g. "<game> why is it fun", "<game> game feel analysis", "<game> review". Look for:
   - **Core verb:** what does it feel like to just move or act?
   - **What players praise:** "the dash feels amazing", "just one more run", "every upgrade changes how you play".
   - **How it teaches itself:** first level, first minute.
   - **How it keeps you playing:** ramp, variety, progression, meta loop.
   - **What critics complain about:** that's a free list of things to avoid.
3. **Distill** each reference into one row of DESIGN.md's **Inspirations** table:

   | Game | Borrow | Change / avoid |
   |---|---|---|
   | Vampire Survivors | auto-attack + pick-1-of-3 upgrades; screen fills with chaos by minute 8 | runs are 30 min, ours are 8; screen clutter, so cap particles for the Deck |

4. **Add your twist.** State what makes this game *not* a clone: the theme, one new mechanic, or a new combination.

**No copying.** Never reuse names, characters, art, music, level layouts or text from other games. Mechanics and feel are fair game; content is not.

If there's no web access, use the canon below and your own knowledge, and say so in DESIGN.md.

## Offline canon

Small, much-loved games and what to take from them.

| Genre | Game | Steal this |
|---|---|---|
| Arcade | **Geometry Wars** | Grid that warps under explosions; enemies with distinct movement "personalities" |
| Arcade | **Downwell** | One button does two things (jump and shoot down); combo while airborne |
| Arcade | **Pac-Man** | Enemies with readable, different chase rules; a power-up flips hunter and hunted |
| Platformer | **Celeste** | Coyote time, jump buffering, instant respawn; generous controls make hard levels feel fair |
| Platformer | **Super Meat Boy** | Tiny levels, death replay of all attempts; failure is funny, not punishing |
| Platformer | **Super Mario Bros. 1-1** | Teach without text: level layout forces you to learn each mechanic safely |
| Roguelite | **Vampire Survivors** | One-stick play, auto-attack, escalating power fantasy, upgrades that combine |
| Roguelite | **Hades** | Death advances the meta-story and unlocks; every run gives something |
| Roguelite | **Spelunky** | Systems that interact (bombs, shopkeepers, physics) create stories |
| Puzzle | **Tetris** | Simple rules, rising speed, near-miss tension; the "Tetris effect" of flow |
| Puzzle | **Baba Is You** | One rule twist reused in surprising ways; each level teaches one idea |
| Puzzle | **Threes / 2048** | One swipe, one merge rule, endless depth; tiny, perfect juice on merges |
| Racing | **Mario Kart** | Items and rubber-banding keep groups close; drift-boost rewards skill |
| Racing | **Trackmania** | Instant restart, ghosts, chasing your own time |
| Rhythm | **Rhythm Heaven** | Each minigame teaches its rhythm with sound cues, not just visuals |
| Rhythm | **Crypt of the NecroDancer** | Rhythm layered onto another genre (dungeon crawling) |
| Cozy | **Stardew Valley** | Daily loop, slow growth, many small goals |
| Cozy | **Mini Metro** | Calm visuals over a slowly tightening challenge; one mechanic, deep |
| Cozy | **Unpacking** | Tactile satisfaction of tidying; story told through objects |
| Party | **Overcooked** | Co-op chaos from shared, interlocking tasks under a timer |
| Party | **TowerFall** | Simple controls, one-hit kills, quick rounds, comebacks |
| Party | **WarioWare** | 5-second microgames: variety itself is the fun |
| Action | **Hotline Miami** | One-hit deaths, instant retry, planning plus execution |
| Shooter | **Ikaruga** | One mechanic (polarity swap) that changes how every bullet reads |
