@AGENTS.md

Pick the skill by intent: making a game → `new-game`; changing, tuning or improving an existing game → `improve-game`; something broken (crash, failing check, controls, performance) → `debug-game`. For a 3D game's models: a new unit or a rebuild from a reference image → `model-unit`; one focused change to one unit, building or prop → `edit-asset`; how units move → `animate-unit` (all three keep the game's `STYLE.md` consistent). You can read PNG files, so after `npm run check` open the cover, hero and screenshot images it prints and improve the art or game until they look right.
