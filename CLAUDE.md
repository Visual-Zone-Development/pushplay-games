@AGENTS.md

Pick the skill by intent: making a game → `new-game`; changing, tuning or improving an existing game → `improve-game`; something broken (crash, failing check, controls, performance) → `debug-game`. For a game's art: a new asset or a rebuild from a reference → `model-asset`; one focused change to one character, prop, sprite or building → `edit-asset`; how things move → `animate-asset` (all three keep the game's `STYLE.md` consistent; add `canvas2d-assets` for 2D games or `threejs-models` for 3D models built in three.js code). You can read PNG files, so after `npm run check` open the cover, hero and screenshot images it prints and improve the art or game until they look right.
