# animate-asset in a PushPlay game

The general `animate-asset` skill covers how things move: cycles, timing, weight and consistency across a game. It needs nothing PushPlay-specific beyond AGENTS.md (*Performance*, and *Settings* for reduced shake / flash).

To render frames for comparison it uses the `model-asset` skill's `scripts/shot.mjs`; see [model-asset.md](model-asset.md) for how to call it in a PushPlay repo.
